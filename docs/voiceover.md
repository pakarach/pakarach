# Voice-over sync (Dan's TTS -> one clip per beat)

1. TTS script (post kit, after approval): .txt. First paragraph = the cover line WITHOUT any label (TTS reads 'COVER:' aloud): series name read aloud, e.g. ใจฟูสตอรี่ / จัดอันดับ / ทันข่าว (+ a 2-4 word topic if it fits ~2 s); align with `--first-is-cover` so a viewer knows on frame 0 what the clip is; then one paragraph per beat in BEATS order, every beat except `cover` and `end`, blank line between, short spoken lines (1-3 s), numbers in Thai words, nothing the TTS shouldn't read. Ask Dan for ~0.5-1 s pauses between paragraphs.
2. When the wav/mp3 arrives: copy it into its own folder, then from the engine folder
   `python3 vo-align.py voice.wav script.txt vo.json --first-is-cover` (numpy + ffmpeg). Check the printed count: paragraphs = beats (minus cover/end) + 1. The COVER paragraph becomes `vo.cover` and plays at t=0.15 (cover beat grows to fit). If Dan sends the cover line as a separate file: `... vo.json --cover cover.wav` (prepended to the mp3; script then has no COVER paragraph). Pauses RMS < -40 dB >= 0.25 s, DP split against expected paragraph length. Read the table: a run of `<<` rows = drift (try silence_db -35/-45, or ask for longer pauses).
3. Build with `--data vo=vo.json`. In video.js nothing else changes when the skeleton is `const B = FK.beats(BEATS, DATA.vo)` + `FK.chillBed({..., voice: FK.voice(DATA.vo, B)})`: beats grow to fit their clip (lead 0.3 s + 0.6 s tail), every at()/end() time shifts with them, clips play in live play and in Render MP4.
4. Test: wait for `window.__voiceOk`, `__ve.play(2)`, no console errors. Say which beats grew; ask Dan to report any line landing on the wrong scene (fix that one boundary in vo.json by hand). A different voice later = redo from step 2 with the same script.
5. Lists / in-scene reveals read item by item: after vo-align, find the pauses inside each list paragraph (RMS < -40 dB >= 0.08 s over that seg), map each item's spoken onset (seconds into the beat's clip) and save them in vo.json as `marks: { s5: [3.76, 4.79, ...] }`. In video.js: `TM(id, i, frac) = marks ? at(id) + B.lead + 0.06 + mark - 0.12 : ph(id, frac)` and drive item reveals, caption splits and SFX from TM (flat-feet clip, Nov 2026). Beat-share timing alone drifts off the voice.

6. Cast names in TTS scripts: write มามะ as "มา-มะ" (Thai TTS reads มามะ as มาม่า); check other cartoon names the same way before sending the script.
