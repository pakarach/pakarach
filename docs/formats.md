# Formats and series (fixed names; palette, typography, intro and end frame never change)

Rotate series across the week; never two of the same series on one day.
- **จัดอันดับ Top 10** (Top N, default 5 or 10): cover -> hook (ranking question) -> countdown, one item per 4-6 s (map highlight + object + number + one line) -> #1 bigger moment (swoop, flash, chime + bell) -> recap of all items on the map. Cosmology rankings (สวรรค์/พรหม/นรก) run here.
- **รู้จักจังหวัด / รู้จักประเทศ**: cover -> hook with one surprising fact -> fly to location -> 4-6 fact cards with a visual each -> closing comparison.
- **A vs B**: cover shows both sides -> split map / side-by-side extrusions, alternating stat rows, winner tally.
- **ถ้า... จะเป็นยังไง** (what if, nostalgia "ถ้าตื่นมาเป็นเด็กยุค..." runs here): hook with a real number -> one continuous world + day-counter HUD -> calm/celebration -> escalating domino disasters (war/terror-scale chaos, not whimsical) -> peak -> long aftermath (1, 3, 5, 10 years, world changing in place) -> recovery or rewind -> "เกร็ดจริง" real facts -> question. Tag fiction "เรื่องสมมติ", facts "เรื่องจริง".
- **ย้อนเวลา** (history time-lapse): HUD year (พ.ศ.) + era + census-only population + progress bar; map evolves (coastline, rivers, city growth via building birth years) with zoom-in dioramas per milestone (docs/dioramas.md); ends with a present-day twist. ~2-3.5 min when Dan asks for long.
- **คนเกิดปี...** (birth year): HUD "ปี พ.ศ. | อายุ"; many world + Thai events, a tech milestone, the year's pop-culture gimmick (Thai or very well-known), a life road, 3 well-known people born that year (Thai first) as name cards + props. Each episode stands alone.
- Nostalgia: a kid's day in one decade and region, morning to night, era-style HUD (VHS/film/Polaroid), a children's game, a regional festival climax, then a researched then-vs-now stat twist (100-icon grid). Read DONE.md (nostalgia section) first so scenes/games/festivals/twists don't repeat.
- **ทันข่าว** (news explainer, Oct 2026): cover asks the question people are googling -> hook -> news timeline (HUD date card) -> map of who said what -> the real answer (myth vs fact, sources) -> why + real Thai examples (day counter) -> how-to steps (step row HUD, worked numbers) -> recap card -> comment question. Neutral, no politics; current local disasters only when Dan asks.
- **ใจฟู Story** (heartwarming true story, Nov 2026; first: Xiao Xiao Xu wedding): narrator-voice captions written as the TTS script (spoken Thai, 2 short lines per beat), chibi hero figures with canvas faces that change mood (smile/sad/joy/tear), thought/speech bubbles only for lines the real people said or clearly paraphrased; cover = the warm end state, hook rewinds to the lonely start; childhood/backstory beats in a soft memory tint + calm bed; map dive with real admin borders (China provinces/prefectures from raw.githubusercontent longwosion/geojson-map-china); climax beat at dusk (stage, lights, petals, hearts) with one emotional line, then recap card + a warm question anyone can answer. ~2-2:20 with voice.
- **วันนี้ในอดีต** (daily On This Day, Nov 2026, posted every day): cover = 3D tear-off calendar of the date + "วันนี้เกิดอะไร?" -> hook from the most surprising item -> 3 sections with HUD tabs วันสำคัญ | วันนี้ในอดีต | ข่าววันนี้ + step dots + year card (ค.ศ./พ.ศ./ปีก่อน) + mini world map dot -> one floating island per item (camera flies island to island, tab beats glide high) -> recap card listing all items numbered -> question answerable from the clip ("เรื่องไหนว้าวสุด คอมเมนต์เลข") + "พรุ่งนี้ <date> มาต่อ"; never ask the viewer's birthday. Thai items: official observances if any, else Thai news of the day; skip politics, lottery, unverified deaths. ~100-110 s.
- **พุทธวิธี** (belief explainer; Profile variant): plain language, a structure the viewer can locate (Mount Meru as vertical map), canon vs commentary tags; Profile = follow one ordinary person through the sutta, pop a 2D "PROFILE #n" HUD card (name huge in the character's colour, alt name, 3 rows revealed one by one, source line) per character, end on the twist that turns back to the viewer. ~4:30 accepted when Dan asked for "สนุกและยาว".

Visual identity: low-poly flat-shaded, saturated; navy #0f1630 bg, ocean #1b2a55, land #2e3f73, teal #2ee6c5, coral #ff5d73, gold #ffc94a (rank #1 always gold), violet #8f7bff, white text (FK.pal). Kanit 800 numbers/keywords, 600 labels, 400 footnotes; rank badges = rounded squares. Signature moves: globe -> Thailand -> province fly-in, regions pop with ease-out-back, counters tick, countdown #10 -> #1. Real objects over bars/lines (planes, boats, buildings, glowing dots on a globe); chunky toy figures for people, real celebrities only as name cards + props; non-human beings get blue-grey skin + glowing eyes.

Brand (fixed): `brand:{name:'RuNgee รู้งี้', series, color:'#2ee6c5', icon:'globe', bg:['#0f1630','#1b2a55'], endLine:'รู้งี้... ติดตามไว้', motif:{notes:['G4','D5','G5'], gap:0.08, timbre:'synth'}}` — only `series` changes. Platform channel name is "RuNgee - รู้งี้ Channel"; the on-video wordmark stays "RuNgee รู้งี้". Never play on the name's possible misreading. Opening sting (<= 0.8 s, under the cover/hook), brand mark (y 90-190), series badge (first 3 s) and the 1.5 s end frame are automatic.

Map helpers: `FK.project(lon0,lat0,k)` + `FK.regions(...)` build extruded regions (scale.z = height; normalize so the max fits the frame, log scale only when values span orders of magnitude and say so; thin provinces get a glow ring or pin). `FK.globe` + `FK.landTest` make the low-poly globe (r=3 needs camera z ~22).

Map data (embed, no runtime fetch): world via prep-world.js (`--data world=`), region insets from world-atlas 50m + topojson-client; Thai provinces/districts from raw.githubusercontent.com/chingchai/OpenGISData-Thailand (simplify `npx mapshaper -simplify 5% keep-shapes`, HTML < 1.5 MB without voice); foreign city districts from GitHub repos via raw.githubusercontent (Overpass/Nominatim/GitHub API are blocked); city rivers from shared district boundaries with shapely. Precompute heavy things in Python into one JSON passed with `--data`.
