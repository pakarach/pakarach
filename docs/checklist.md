# Outline checklist (Dan's standing feedback) — check every outline before sending

Cover (frame 0 = thumbnail)
- t=0 is a finished cover: the most telling picture of the story + title fully visible (caption `instant:true`, 2-3 lines 120-150px, keyword gold, <= 1 small sub-line), `coverAt0:true`. Own `cover` beat ~1.5-2 s, then a story move (iris/glide) into the hook. Title and labels inside the 3:4 crop (y ~300-1500). Hook continues the thought, never repeats the title.

Story (one thread, complete in itself)
- Each beat answers the question the previous one raised (cause -> effect -> so what). Plan the why, not only what/when/where.
- Answer the obvious viewer "แล้วทำไม...?" before it is asked (source: sutta first, then commentary).
- Set up before payoff: a new element needs a beat that creates the need for it ("อยู่ๆ มายานบิน" = bad).
- No outside context needed; explain names/terms in a few words; no cross-clip references unless Dan asks.
- Define the metaphor/measure at the start and keep it on screen (gauge). No half-sentences ("ยังไม่ใช่เวลา!" for what?).
- Hook makes a promise (best a reveal); ending pays it off with a one-screen recap, then a comment question anyone can answer from the clip.
- Never label the twist ("หักมุม!"), no fake hype numbers ("99% ไม่รู้"). Include the modern angle when it fits (blackout = no AI). City/country history includes the geography and neighbour context that pay off later as causes.

Detail (rich pictures, light words)
- Detail goes into visuals: modeled objects, people acting out the beat, 2-3 visual beats per item. Parallel items get equal depth.
- One idea per beat, one short line (+ optional small sub-line), headline >= ~58px, plain spoken Thai; jargon only as a small in-scene label.
- Year/era clips: plenty of concrete events + one pop-culture hook people remember.

Smooth / pace
- One continuous world; cuts only as story moves with the HUD kept on. Camera never dead-stops.
- Hold each caption >= ~3 s (short line), ~4-5 s (number or second line). If Dan says "อ่านไม่ทัน", stretch everything by one factor in a wrapper.

Wording
- Name the polity of the period (อยุธยา, สยาม, ล้านนา, ล้านช้าง), never "ไทยแท้" for pre-modern things; check which kingdom a place belonged to; culture zones labelled approximate.
- Neighbours: neutral wording, no blame, never "พี่น้อง/บ้านพี่เมืองน้อง" (use เพื่อน/ญาติ).
- Religion: tag พระไตรปิฎก vs อรรถกถา/ไตรภูมิ on screen (+ "ภาพจำลองตามคติความเชื่อ"); a commentary segment carries a large "อรรถกถา" banner; name where folk images come from only when verified. Hell punishments symbolic, no gore.
- Leave a current local disaster out of a light clip unless Dan asks.

Accuracy
- Every number/date researched (official sources first; Wikipedia as pointer; SuttaCentral/84000.org for texts), data year on screen once, one source line at the end. Unverified -> leave out or qualitative. Don't mix measures in one counter. Sources disagree -> show the range / neutral word. Illustrative parts labelled สมมติ/ประมาณ/ภาพจำลอง. Drop metrics that need a definition (GPP per capita as "รวย").

Uniqueness
- Own topic, own data set, >= 1 angle/twist no earlier clip used; no reused hook sentence, scene order or ending line two clips in a row. Check DONE.md. Label as AI-generated where the platform asks.
